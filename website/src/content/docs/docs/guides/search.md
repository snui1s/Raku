---
title: Search and commands
description: Jump to any note or run a command with Ctrl K.
---

Press `Ctrl` + `K` anywhere in Raku to open the command palette. You can also click **Search or jump to** at the top of the sidebar.

## Find a note

Start typing. The list shows notes whose **title** contains what you typed, most recently edited first, with the folder each one is in. Use `↑` and `↓` to move and `Enter` to open a note. Press `Esc` to close the palette.

Search matches titles only, not the full text of notes. The palette shows up to 8 matching notes.

## Run a command

The same list includes commands that match what you typed:

- **New note**
- **New folder**
- **Toggle light / dark**
- **Zen mode** (`Ctrl` + `Shift` + `Z`)
- **Export note**
