title: Keyboard shortcuts
description: The Windows keyboard shortcuts for finding notes, formatting text, zooming and focusing in Raku.
---

These shortcuts are for the Windows app. The search box on this documentation website searches the guides, while `Ctrl` + `K` in Raku searches your note titles.

## Find notes and focus

| Shortcut | Action |
| --- | --- |
| `Ctrl` + `K` | Open or close **Search or jump to**. |
| `↑` / `↓` | Select a result in the command palette. |
| `Enter` | Open the selected note or run the selected command. |
| `Esc` | Close the command palette, or leave Zen mode. |
| `Ctrl` + `Shift` + `Z` | Enter or leave **Zen mode**. |
| `Ctrl` + `Shift` + `T` | Show or hide the editor toolbar. |

To create a note, click **New note** in the sidebar, or open the command palette and choose **New note**.

## Format text

These shortcuts work while the note editor has focus. Select text to change it, or toggle a style before you type.

| Shortcut | Action |
| --- | --- |
| `Ctrl` + `B` | Bold. |
| `Ctrl` + `I` | Italic. |
| `Ctrl` + `U` | Underline. |
| `Ctrl` + `Z` | Undo an edit. |
| `Ctrl` + `Y` | Redo an edit. |
| `Ctrl` + `C` / `X` / `V` | Copy, cut or paste. |
| `Shift` + `Enter` | Add a line break within the current paragraph. |

Use `Ctrl` + `Y` for redo: Raku uses `Ctrl` + `Shift` + `Z` for Zen mode.

See [Writing and images](/docs/guides/writing-and-images/) for toolbar controls and checklists.

## Zoom the paper

| Shortcut | Action |
| --- | --- |
| `Ctrl` + mouse wheel over the note | Zoom the paper. |
| `Ctrl` + `+` (or `Ctrl` + `=`) | Zoom in. |
| `Ctrl` + `-` | Zoom out. |
| `Ctrl` + `0` | Reset paper zoom to 100%. |

Paper zoom ranges from 50% to 250%. To change the sidebar, menus and header size, use **Settings → Appearance → Interface scale**. Read more in [Zoom and settings](/docs/guides/zoom-and-settings/).
