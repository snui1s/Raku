## Zen mode

Press `Ctrl` + `Shift` + `Z`, choose **Zen mode** in the command palette, or click the Zen mode button at the right of the header.

Zen mode hides the sidebar and header so the note has more room. Press `Esc` or `Ctrl` + `Shift` + `Z` to leave it.

The editor toolbar has its own visibility setting. Press `Ctrl` + `Shift` + `T` to hide it as well, and press the same shortcut to bring it back.

## Pomodoro timer

The timer is in the header and starts at **25:00**.

1. Before starting, use **−** or **+** to change the duration in five-minute steps, from **5** to **60 minutes**.
2. Click the timer to start the countdown.
3. Click it again to stop. Stopping resets the countdown to the chosen duration.
4. When the time runs out, Raku shows a brief confetti celebration. Click the timer to start another session.

The duration controls are available while the timer is stopped. Sessions do not automatically start a break or another countdown.

:::tip[Start the timer before Zen mode]
Start a session, then enter Zen mode. The timer keeps counting while the header is hidden. Leave Zen mode to see the remaining time or stop it.
:::

Keep Raku running during the session. Closing and reopening the app resets the timer.

## Set up a quiet workspace

- Adjust **Paper → Width** and **Line spacing** in [Settings](/docs/guides/zoom-and-settings/).
- Choose a light or dark appearance and a color palette.
- Turn on **Reduce animations** in Settings to reduce interface transitions.

See [Keyboard shortcuts](/docs/guides/keyboard-shortcuts/) for a quick reference.
